# Charleston Solitaire

Klondike solitaire where every card is BDB. 52 cards, 100 roasts, one guy who averaged 2.0 points a game.

Play it on GitHub Pages: https://terryjones1995.github.io/BDB/

- Draw 1 or Draw 3
- Drag cards or tap to auto-move
- Undo, hints, auto-finish, best time
- A new roast every time a card comes off the deck

Made for laughs. All roasts are fictional.
